# 42 Lisboa — Common Core

My work from the 42 Lisboa Common Core, completed between September 2023 and
October 2024.

Each project now lives in its own repository, linked below, with its full
commit history preserved. This repository remains as an index and as an archive
of the original combined tree.

## Common Core

| Project | Description | Grade |
|---|---|:--:|
| [libft](https://github.com/goncalo1021pt/libft) | A C library written from scratch — libc reimplementations, string and memory utilities, linked lists | 125% |
| [ft_printf](https://github.com/goncalo1021pt/ft_printf) | Reimplementing `printf`, variadic arguments and all | 100% |
| [get_next_line](https://github.com/goncalo1021pt/get_next_line) | Reading a file descriptor line by line, with state preserved between calls | 125% |

## About this repository

Everything here was originally developed in this single repository. It has since
been split so that each project stands on its own, using `git filter-repo` —
every project repo carries its real commit history, dates and authorship rather
than a flattened snapshot.

The complete pre-split tree is preserved under the
[`pre-split-archive`](https://github.com/goncalo1021pt/42lisboa/releases/tag/pre-split-archive)
tag.
